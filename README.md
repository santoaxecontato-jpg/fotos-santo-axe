# Fotos de produtos Santo Axé

Repositório público com as fotos dos produtos Santo Axé, usado como origem das imagens externas dos cadastros.

Cada foto pode ser acessada diretamente pelo link:

```
https://raw.githubusercontent.com/santoaxecontato-jpg/fotos-santo-axe/main/<pasta>/<arquivo>
```

Exemplo: `https://raw.githubusercontent.com/santoaxecontato-jpg/fotos-santo-axe/main/barro/caneca-de-barro.jpg`

Os nomes de pastas e arquivos usam apenas letras minúsculas, números e hífens (sem espaços nem acentos), para que os links funcionem em qualquer sistema.
